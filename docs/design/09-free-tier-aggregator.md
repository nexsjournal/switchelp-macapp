# 09 · 「免费额度」聚合中心：方案

> 2026-09-30 · 应用户需求设计：一个**信息汇集**页面——用户在这里能看到「哪里有合规的免费 token / 额度」（哪些 IDE、Agent、模型厂商在送），点链接跳去官方自己领。
> 事实底座是 [docs/research/06-aitracker-research.md](../research/06-aitracker-research.md) 第 9 节（2026-09-25 逐条抓官方文档核实的快照）；本方案只做产品化设计，不重复列举证据。

## 1. 定位与边界（这条决定整个方案的形状）

**做什么**：把「厂商官方公开发布的免费额度」汇成一份可读、可点的清单——只汇集**信息**，跳转**官方页面**。

**不做什么**（来自调研 06 §9.0 的三分法，C 类整类拒之门外）：

| 类别 | 本页做不做 | 理由 |
| --- | --- | --- |
| B 类：厂商公开发布的免费档 / 试用金 / 免费模型 | ✅ **本页的全部** | 合规、公开、可标注出处 |
| A 类：你自己的计划额度 | ❌ 不在这页 | 它是本机真值，已经在「用量统计 → 本机计划额度」卡上（读本机 rollout 的 `rate_limits`），两件事不要混在一个页面里 |
| C 类：共享 Key、批量注册试号、抓来的凭据 | ❌ **永远不做** | 违反 ToS、账号与法律风险（06 §9.6：2024 年 GitHub 公开仓库新增泄露密钥 2377 万条，2022 年泄露的到 2025 年仍有 70% 有效） |

一句产品立场写进页面：「本页只汇集官方公开的免费额度信息；领取用你自己的账号，限额以各家文档为准。」——它同时是对用户的说明和对维护者的约束。

## 2. 信息架构：侧栏「扩展」分组下的独立页面

卡片（照内容中心资讯卡与 GitHub 卡的既有形状）：

- **厂商名** + 类别徽章（能用 `@lobehub/icons` 的上真实图标，见 2026-09-30 工具页的做法；没有的用首字块）；
- **免费内容一句话**（如「`:free` 模型变体，50 次/天」）+ 适用条件（如「未购过额度时」）；
- 两个动作：**去领取**（官方注册/控制台页）与**官方说明**（写明限额的文档页）——都走 `open_external_url` 命令（只放行 http/https 的守卫已就位），本应用不做任何中间页；
- **最后核实日期**是卡片的必显字段；清单里已确认失效的条目（如 GitHub Models 于 2026-07-30 退役）置灰 + 「已退役」徽章，**不删**——它是「别再信旧攻略」的教育样本。

## 3. 数据模型与来源

### 3.1 条目 schema（随包 JSON，版本化）

```jsonc
{
  "version": 7,                       // 清单版本，单调递增
  "verifiedAt": "2026-09-25",
  "entries": [{
    "id": "openrouter-free-tier",
    "provider": "OpenRouter",
    "icon": "openrouter",             // 对应 @lobehub/icons 的 id；无则空
    "category": "model_free_tier",    // model_free_tier | trial_credit | student_dev | local
    "title": ":free 模型变体每日免费调用",
    "quota": "未购额度 50 次/天；累计充值 ≥$10 后 1000 次/天；20 次/分",
    "conditions": "需要注册账号并生成自己的 Key",
    "docsUrl": "https://openrouter.ai/docs/api-reference/limits",
    "claimUrl": "https://openrouter.ai/keys",
    "presetId": "openrouter",         // 与网关预设目录联动（见 §5）；无则省略
    "retired": null,                  // 退役条目改为 { "at": "2026-07-30", "note": "GitHub Models 已下线" }
    "source": "官方文档"               // 来源只有一种：官方文档/官方页面
  }]
}
```

字段设计的三条硬规则：**每个条目必须有 docsUrl**（没有官方文档背书的免费额度不收录，比如论坛帖、聚合博客）；**quota 写文档原话的换算**而不是营销话术；**核实日期必填**——免费额度是快照信息，这是它与其它页签最不同的地方。

### 3.2 来源与更新

- **随包基线**：上面这份 JSON 随应用打包（离线可用，首次启动就有内容）。
- **在线刷新**（✅ 2026-10-06 落地，与最初设想的两处偏差见下）：随包清单（`freeTierData.ts`）有一份**导出件** `freeTierData.json` 提交在本仓库，应用从 raw main 拉它（地址固定在 src-tauri 的 `FREE_TIER_CATALOG_URL`）。打开页面距上次成功检查超过 24 小时就静默查一次 + 页头「检查更新」随时手动查；拉不到或数据没过校验（`freeTierRemote.ts` 按**不可信输入**做形状校验）就继续用随包的。**只认 `version` 更新的一版**，同版本不覆盖——所以改清单必须连 version 一起抬。断网时页面照常可用，页头仍是「随应用更新」。
  - 偏差一：没建 `switchelp-data` 仓库——应用仓库本身就是公开的，直接用 raw main，少一个仓库要维护；以后要迁走只改 Rust 里那一行常量。
  - 偏差二：没走内容中心的抓取管线（ETag/调度/退避）——一份我们自己维护的静态 JSON 用不上那套礼节，打开页面时顺手查一次比定时调度更贴合「用户主动来查」的页面属性；缓存记在 webview localStorage，失败不记账、下次打开重试。
- **人工维护节奏**：每月对照官方文档复核一遍（十几家，半小时的量）；复核改动改清单 → 重新导出（`FREE_TIER_EXPORT_UPDATE=1 pnpm vitest run src/features/content/freeTierData.export.test.ts`）→ 随代码提交推送，**过期只是一次数据更新，不再是一次发版**。GitHub Models 的退役就是活例：60 天内没维护，用户就会看到一批过期攻略。
- **目录型社区仓库**（free-llm-api-resources 等）：只做人工核对的参考起点，**不直接抓取喂给产品**——它们自己都声明限额随时会变，精度不够（06 §9.5）。

## 4. 合规红线（写进实现，不靠自觉）

1. 不收录任何需要「绕过正常注册流程」才能拿到的额度；不出现任何 Key（哪怕示例格式）。
2. 不代领、不代注册、不代理请求：页面只有跳转链接，领取动作发生在官方站点。
3. 每个条目的 quota 旁边以小字标注「以官方文档为准」，卡片的「官方说明」链接直达写明限额的那一页。
4. 已退役条目不静默删除——置灰展示，防止用户拿着旧攻略白跑。
5. A 类（本机计划额度）不进这页：它是用量统计页的职责，两页各说各的事实。

## 5. 与网关的衔接（点完「领取」回来的下一步）

拿到 Key 之后，用户要回到网关把厂商接进来。两个衔接点：

1. **预设联动**：条目带 `presetId` 时（OpenRouter、SiliconFlow、智谱、千问、MiniMax、Ollama 已在预设目录里），卡片加一个「在网关中接入」按钮——跳到网关页并打开「添加供应商」弹窗、**预选中对应预设**（表单已填好地址与协议，用户只差粘贴 Key）。没有对应预设的条目不显示这个按钮。
2. **文案指路**：页签顶部的说明行带一句「拿到 Key 后，到『网关 → 添加供应商』选择对应厂商粘贴即可」。

这一步让「看到信息 → 领取 → 接入」三条腿都齐了，且每条腿都只做自己的事。

## 6. 分期与验收

| 期 | 内容 | 验收 | 状态 |
| --- | --- | --- | --- |
| 第 1 期 | 随包基线清单（22 条：17 家有免费档/试用金、2 条「没有免费档」反例、1 条已退役）+ 侧栏独立页「免费额度」+ 类别筛选 + 卡片网格 + 跳转守卫 | 离线可看；每张卡有核实日期与官方说明链接；两主题审计全零 | ✅ 2026-09-30 落地 |
| 第 2 期 | 在线刷新（仓库 raw main JSON + 打开页面 24h 节流自动查 + 手动「检查更新」） | 断网/坏数据回落随包版本；采纳更新后页头变「已在线同步」、缓存跨重启保留、24h 内不再请求（真机 A/B 实测） | ✅ 2026-10-06 落地（直接用本仓库 raw main，无需另建 `switchelp-data`；细节见 §3.2） |
| 第 3 期 | `presetId` 联动「在网关中接入」 | 从卡片一步进入预填好的添加供应商弹窗；无预设条目不显示入口 | ✅ 2026-09-30 落地（OpenRouter/智谱/千问/硅基流动/Ollama 五家有预设联动） |

第 2 期落地后，清单更新 = 改 `src/features/content/freeTierData.ts` + 抬 version + 重新导出 JSON 一起提交；已装的应用最迟在下次打开页面 24 小时后拿到新清单，不用等发版。

**明确不做**：不做额度实时查询（除用量页已有的本机计划额度）、不做聚合代理（06 §9.7 的 (b) 形态）、不做任何自动注册、不收录 C 类信息、不做论坛/博客二手信息的转载。
